# Skill: seo

- Choosing keywords for news or pages  
- Title / description / slug  
- Internal linking  
- GEO / Japan search visibility (with skill **lang** + `geo-japan.md`)  

## Required context

1. Persona `.cursor/agents/seo.md`; rule `content-seo` when reviewing copy  
2. `documentations/seo-keywords.md` — P1 web first, then P2; P3 AI only for upsell  
3. `documentations/pages.md` — real routes / canonical targets

5. For JA: `documentations/geo-japan.md`

## Rules

- One primary keyword per piece; don’t stuff  
- Prefer linking to `/services/web/`, `/#popular-services`, strong `/news/` posts  
- Meta: factual, benefit-led; brand Dolphin Software  
- Do not invent GSC numbers — if missing, say “cần check GSC”  
- Confirm-before-acting before editing meta/routes/docs  

## Output checklist

- [ ] Primary keyword + intent  
- [ ] Title (≈50–60 chars where sensible)  
- [ ] Meta description  
- [ ] Suggested slug (news) or path  
- [ ] 1–3 internal links  
- [ ] Locale note if non-VI
