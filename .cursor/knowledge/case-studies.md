# Case studies (facts only)

Portfolio: `#works` / `/works/[slug]/` (billiard, badminton, tickets, beauty, cafe, clinic, …).

## Rules

- Chỉ mô tả case có trong `lib/works-details` / works pages  
- Không bịa metrics (traffic %, revenue) trừ khi đã ghi trong source  
- Prefer: khách (khái quát) → vấn đề → cách làm → kết quả  

## Grow this file (human)

Sau mỗi dự án thật, bổ sung block ngắn:

```
### [Tên khái quát ngành]
- Pain:
- Approach (Build / Modernize / Automate / Care):
- Result (chỉ fact đã confirm):
```

Đó là nguyên liệu tốt nhất để AI viết “giống người”. Chưa confirm → **TODO: confirm with founder**.
