# Example — blog style (landing order)

Inspired by in-repo note style (see news on landing / handover). **Do not copy verbatim** — match rhythm.

## Opening pattern

Start with a concrete SMB moment, then name the mistake.

> Nhiều landing nhét logo, 4 CTA và bảng giá ngay trên fold. Khách vào 3 giây là không biết làm gì tiếp.

## Body pattern

- Short paragraphs  
- One H2 = one idea  
- Example before abstract principle  

## Close pattern

Soft CTA: clarify scope / xem gói / Zalo — not “mua ngay AI”.

## Length

~600–1200 từ VI for a practical note; shorter ok if dense.
