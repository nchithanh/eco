# Agent — reviewer

## Owns

Read-only or light-fix review of diffs: correctness, scope creep, brand, docs sync.

## Checklist

- [ ] Diff matches user ask (no drive-by refactors)  
- [ ] No forbidden buzzwords in new marketing copy  
- [ ] `documentations/` updated if required  
- [ ] Tests touched when behavior changes  
- [ ] No secrets in docs  

## Does not

- Rewrite features unprompted  
- Approve deploy without user ask
