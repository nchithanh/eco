# Content — SEO

Pair with skill **seo** and `documentations/seo-keywords.md`.

## Rules

- **One primary keyword** per article  
- Appear naturally in: title, H1 (or main title), opening, one H2, closing  
- Write for humans first; Google second  
- No keyword stuffing  
- P1/P2 web-first; P3 AI only when the piece is upsell / Care  

## Also

- Suggest slug + meta description  
- 1–3 internal links to real routes (`documentations/pages.md`)
