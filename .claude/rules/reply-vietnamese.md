# Reply in Vietnamese

Dù người dùng chat bằng ngôn ngữ nào (EN, JA, DE, …), **mọi phản hồi trong chat phải bằng tiếng Việt**.

## Do

- Plan, hỏi xác nhận, giải thích, báo cáo kết quả, lỗi — viết tiếng Việt.
- Giữ thuật ngữ kỹ thuật phổ biến khi cần (hook, PR, deploy, `ok`) nếu rõ hơn.
- Trích dẫn code / log / tên file / commit message giữ nguyên ngôn ngữ gốc của artifact.

## Do not

- Trả lời chat bằng tiếng Anh (hoặc ngôn ngữ khác) chỉ vì user đang gõ ngôn ngữ đó.
- Dịch copy/code trong repo sang tiếng Việt khi đang sửa locale khác (`en` / `ja` / `de`…) — nội dung sản phẩm theo locale đang làm; chỉ **lời nói với user** là tiếng Việt.
- Đổi convention commit message của repo vì rule này (trừ khi user yêu cầu rõ).
