# Content — brand

Read: `.cursor/knowledge/company.md`, `company-opinion.md`, `company-values.md` + `documentations/brand-voice.md`.

## Voice

We speak like a **founder** who ships websites — not like a sales script.

Prefer: short, clear, practical, examples, a point of view (`company-opinion.md`).  
Help the reader **understand first**. Do not hard-sell.

## Positioning

**Build · Modernize · Automate · Care** — outcomes, not a tech menu.

## USP order (cold)

1. Build — website / web app — clear scope, handover  
2. Optional: Modernize / Automate / Care when pain matches  

Never cold-open SMB with “AI Agent”.

## Brand name

**Dolphin Software** only in new copy.
