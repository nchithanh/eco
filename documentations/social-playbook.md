# Social playbook — Dolphin Software

Use with **mode-social** + skills **lang** / **seo** (light).

## Goal

Traffic → **lead** (Zalo / quote), mainly **website** interest. Soft upsell Dolphin Care only when relevant.

## Channel lengths (rough)

| Channel | Length | Notes |
| --- | --- | --- |
| Zalo | Short, conversational | Strong for VN SMB |
| Facebook | Short–medium | Hook + 1 CTA link |
| Instagram | Short + line breaks | Hashtags spare |
| TikTok | Hook in 1st line | Script / on-screen text friendly |

## Post skeleton

1. **Hook** — problem or outcome (website / clarity / leads)  
2. **Body** — 1–3 lines proof or offer  
3. **CTA** — `https://dolphin-software.io.vn/` path or Zalo  
4. Optional soft Care line  

## Do / Don’t

- Do: web-first, real URLs from `pages.md`  
- Do: match `brand-voice.md`  
- Don’t: lead with “AI Agent” for cold SMB  
- Don’t: fake social proof numbers  

## Cadence (suggested)

- ≥1 meaningful post / week on primary VN channel  
- Align 1 post with each new `/news/` when possible  
- JA experiments: see `geo-japan.md`
