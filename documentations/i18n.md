# i18n

## Locales

`vi` | `en` | `ja` | `de` | `zh` — type `Locale` in `lib/i18n/types.ts`.

- Default locale: see `DEFAULT_LOCALE` in `types.ts` (currently `ja` in layout/`lang`)
- Runtime: `LocaleProvider` (`lib/i18n/LocaleProvider.tsx`), storage key `kuct-locale`
- Switcher: `components/LanguageSwitcher.tsx`
