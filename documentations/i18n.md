# i18n

## Locales

`vi` | `en` | `ja` — type `Locale` in `lib/i18n/types.ts`.

- Default locale: see `DEFAULT_LOCALE` in `types.ts` (currently `en` — boot script + `LocaleProvider` fallback when no stored/navigator match)
- `LocaleProvider`: first render always `DEFAULT_LOCALE` (SSR/hydration match); real locale applied in `useEffect` after boot/`localStorage`
- Boot loader (`AgentLoader`): copy always **EN** (`getDictionary("en").loader`), independent of UI locale
- Runtime: `LocaleProvider` (`lib/i18n/LocaleProvider.tsx`), storage key `kuct-locale`
- Switcher: `components/LanguageSwitcher.tsx`
