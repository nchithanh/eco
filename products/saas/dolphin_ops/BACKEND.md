# Backend lives in another repo

`git@github.com:nchithanh/dolphinOpsBackend.git`

```bash
git clone git@github.com:nchithanh/dolphinOpsBackend.git
```

Local checkout in this workspace (nested git): `backend/`. **documentations/**, **AGENTS.md**, and **README.md** stay visible to `eco`. App code (`cmd/`, `internal/`, `go.mod`, …) lives in the private BE repo.
